# Blog Platform

Django yordamida yaratilgan blog platformasi.

## Loyiha haqida

Ushbu loyiha foydalanuvchilarga blog postlarini ko‘rish, qidirish,
saralash, yoqtirish va izoh qoldirish imkonini beradi.

## Asosiy imkoniyatlar

- Foydalanuvchi ro‘yxatdan o‘tishi
- Tizimga kirish va chiqish
- Profil bilan ishlash
- Post yaratish
- Postni tahrirlash
- Postni o‘chirish
- Postlarni ko‘rish
- Postlarni qidirish
- Postlarni saralash
- Kategoriya bo‘yicha postlarni ko‘rish
- Like bosish va like'ni olib tashlash
- Yoqtirilgan postlarni ko‘rish
- Postlarga kommentariya yozish
- O‘xshash postlarni ko‘rsatish
- Admin panel orqali boshqarish

## Texnologiyalar

- Python
- Django
- SQLite
- HTML
- CSS
- Django Templates
- CKEditor
- Git
